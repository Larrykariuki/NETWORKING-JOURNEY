## Subnetting
Is the process of Dividing a network into smaller networks called subnets, subnet mask tells us which part represent the network and which one represents the number of hosts devices on the network
### Importance of subnetting 
Organize networks,
Reduce unnecessary network traffic,
Use IP adresses  more efficiently
seperate groups of devices
improve network  management and security
### Example
A Large neighbourhood divided into different streets
### What I Learned 
Subnetting is the process of dividing a network into smaller more manageable networks for efficiency called subnets,subnet mask tells us which part represent the network and which one represents the number of hosts devices on the network
e.g, a /24 network can be divided into multiple /26 networks
For /26
0......63,
64......127,
128......191,
192.......255,
where there are 64 total addresses,62 usable host addresses,1 network address and 1 broadcast address,that are reserved
I learned how to identify subnet boundaries or ranges
192.168.10.0/26, 192.168.10.64/26, 192.168.10.128/26, 192.168.10.192/26,subnetting itself does not provide complete security on the network.Routing rules and firewalls can be used for control of communication between the subnets,subnetting divides the ip addresses into smaller networks while segmetation seperates the devices or networks into groups
