## Network Segmentation
is the process of dividing a network into seperate segments or security zones
Organizations can use network segmentation to:
control network traffic, Restrict access  between systems,
Reduce unnecessary exposure,
limits lateral movement after a compromise,the firewall or rules for routing can controll what traffic is allowed between the segments
### Example
A company structure might be like
Emloyees---segment 1-----Servers------segment 2-------guest wifi-------segment 3-------cctvs------segment 4

notice each group is seperated from others this helps with (a) Security-If an attacker exploits or compromises a part of the network, segmentation can help limit their movement(lateral movement) within the network (b) Organization-Devices can be grouped together in order (C) Performance- when u seperate  the traffic u can reduce unnecessary traffic between groups (D) Access control- The network administrators can control which segments are allowed to communicate with each other so network segmentation is dividing a network into smaller sections
