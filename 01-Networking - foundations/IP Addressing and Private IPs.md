## Private IP Address
Private IP addresses is used inside a local network and  are commonly used by devices in schools,companies,hospital inside homes and any other internal networks
## Public IP Address
is used on the public internet,An organization or a company or a home can have their devices using private ip addresses inside while the router routes or communicate with the internet using a public IP address which uses NAT to translate their private source addresses to the homes public ip address
## What i have learned
Private IP addresses are used inside private networks while public IP addresses can be routed across the public internet and the router and firewall use NAT to translate the private addresses into public IP addresses,private addresses are not routable across the public internet but they can be routed in private networks or vpns,firewalls rules permit or deny traffic while NAT changes address information and can prevent some  inbound connections when there is no translation.A public address doesnt mean that a device can be reachable from the internet it can be assigned to a gateway  rather than NAT or firewalls
