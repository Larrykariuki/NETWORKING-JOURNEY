## ARP
stands for address resolution protocol and is a protocol that is used in a network to discover the devices mac address that is associated  with a local ip address 
### Example
If a device knows the ip address of another device but does not know the mac address of the device on a local area network then the device shall use the ARP protocal
### What I Learned 
ARP helps the device to discover mac addresses in a ipv4 local area network,my computer sends an ARP request 
"Who has 192.168.1.20" and the request is broadcast on the local network then the device that has the ip address responds with its MAC address then my computer can now use the mac address to create an ethernet frame and send the data, IP tells me where the device is.ARP is the protocal that helps me find its mac address then the mac address allows the ethernet frame to reach the device on the local network
