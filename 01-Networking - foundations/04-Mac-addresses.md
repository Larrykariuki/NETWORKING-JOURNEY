## MAC Adresses
a device fingerprint/identity and cannot change used for communication on the local network but sometimes can be spoofed or changed in software
### Example
MAC address is like a device's local network identifier, when data needs to travel from a device to another device in the same local area network the ethernet uses the mac address to deliver the data to the specific correct destination ,it looks like this 00:1 A:2B:3C:4D:5E 
### What I Learned
IP addresses helps to identify the destination of the network while MAC address is used to identify the specific device on the local area network when my laptop/computer communicates with another device on the same local area network the ethernet or wifi frames use the link -layer addressing protocol to deliver the data
.Mac address:Used for delivery across a local network while ip address: Used to address traffic across ip networks,A device can have both an ip and a mac address,understanding mac address helps to interprete network traffic,to investigate devices on a local area network and learn how switches forward ethernet frames
